# stock-picks — AI 주식 추천 · 성과 추적

코스피·코스닥·S&P 500·나스닥을 거래 가능 시간(정규장 + 프리·애프터마켓) 동안 1시간마다 감시해 추천 종목을 고르고, 추천 이후 성과를 계속 추적합니다.

- **차트 분석 추천** (시장별 하루 최대 3종목): 정배열 추세 + 20일 고점 돌파(거래량 동반) 또는 20일선 눌림 반등,
  3개월 상대강도 상위 종목. 시장이 하락 국면이면 기준을 더 엄격하게 적용. — `scripts/run.py`, GitHub Actions
- **투자자 방식 추천** (시장별 하루 최대 3종목): 최근 수익률 상위 투자자·펀드의 매매 + 수급·시장 정세를 종합한
  Claude 분석. — `CLAUDE_TASK.md`
- **전통 전략 추천** (시장별 하루 최대 3종목): 가치(저PER·저PBR), 고배당, 퀄리티(고ROE·저부채),
  역추세(RSI 과매도 탈출), MACD 골든크로스, 볼린저밴드 하단 반등. 전략별로 돌아가며 고르고 성과로 비중 조정.
- **단기 스윙** (시장별 하루 최대 3종목, 1~5일, 모의 검증): 전일 고가 돌파 + 거래량 급증 + 단기 정배열.
- **성과 추적**: 추천가 대비 수익률, 같은 기간 지수 대비 초과수익, 최고·최저.
  지수 대비 +3%p 이상이면 '잘한 추천', -5%p 이하나 손절선 이탈이면 '아쉬운 추천'. 20거래일 후 최종 평가.

화면: GitHub Pages (`docs/index.html`). 데이터: `docs/data/`.
시세: Yahoo Finance(무료, 지연 시세). 투자 권유가 아니며 판단과 책임은 본인에게 있습니다.

## 수동 실행
Actions 탭 → hourly-scan → Run workflow (markets: `all`이면 4개 시장 전부 스캔)
